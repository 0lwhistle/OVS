## 模块引脚分配

### 1. INMP441 麦克风（左上方 → 左边引脚）

**模块引脚**: VDD, GND, SCK, WS, SD, L/R

| 模块引脚 | 功能 | ESP32 GPIO | ESP32位置 | 说明 |
|----------|------|------------|-----------|------|
| VDD | 电源 | 3.3V | - | 电源 |
| GND | 地 | GND | - | 接地 |
| SCK | 时钟 | GPIO6 | 左边Pin6 | BCLK信号（位时钟） |
| WS | 字选择 | GPIO5 | 左边Pin5 | WS信号（字选择） |
| SD | 数据 | GPIO7 | 左边Pin7 | 数据输出 |
| L/R | 左右声道 | GND | - | 左声道 |

**接线图**:
```
ESP32左边 (Pin5-Pin7，连续)       INMP441麦克风 (左上方)
Pin5 GPIO5 (WS)   ──────────────► WS
Pin6 GPIO6 (BCLK) ──────────────► SCK
Pin7 GPIO7 (DIN)  ◄────────────── SD
```

## 走线规划

### 左边引脚走线（左边模块）

```
Pin5-8 (GPIO5/6/7/15) → I2S：麦克风（左上方）+ 功放（背面左边）
Pin9-11 (GPIO16/17/18) → I2C：触摸（正下方右侧）+ ath30（右边中间）
Pin12-16 (GPIO8/3/46/9/10) → LoRa（左下方）
Pin19 (GPIO13) → W25Q128 CS（右下方）
Pin20 (GPIO14) → LED
```

### 右边引脚走线（右边模块）

```
Pin6-8 (GPIO42/41/40) → SPI：显示屏（正下方）+ W25Q128（右下方）
Pin9 (GPIO39) → 触摸 RST（正下方右侧）
Pin10 (GPIO38) → 显示屏背光（正下方）
Pin16-18 (GPIO48/47/21) → 显示屏控制（正下方）
```
