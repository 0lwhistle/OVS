## 二、设计流程

### 第1步：创建工程
1. 打开嘉立创EDA
2. 新建工程 → 命名为"ESP32-S3-SmartAssistant"
3. 新建原理图
4. 新建PCB

### 第2步：绘制原理图

#### 2.1 添加元件
在元件库中搜索并添加：

**核心板**：
- 搜索"ESP32-S3"或"22x2排母"
- 添加22x2排母（44Pin）

**模块连接器**：
- 搜索"2.54mm排母"
- 添加：
  - 1x7排母 x2（LoRa、功放）
  - 2x3排母 x1（麦克风）
  - 1x5排母 x1（W25Q128）
  - 1x4排母 x1（ath30）
  - 2x5排母 x3（电源模块）

**FPC转接板**：
- 搜索"2.54mm排针"
- 添加：
  - 2x5排针 x1（显示FPC）
  - 2x3排针 x1（触控FPC）

#### 2.2 连线
按照 `hardware/wiring_diagram.md` 中的引脚分配连线：

**SPI总线**：
```
GPIO10 (MOSI) → 显示屏、W25Q128
GPIO11 (MISO) → W25Q128
GPIO12 (SCLK) → 显示屏、W25Q128
GPIO13 (CS_W25Q128) → W25Q128
GPIO21 (CS_LCD) → 显示屏
GPIO47 (DC_LCD) → 显示屏
GPIO48 (RST_LCD) → 显示屏
GPIO4 (BL_LCD) → 显示屏
```

**I2S总线**：
```
GPIO5 (BCLK) → 麦克风、功放
GPIO6 (WS) → 麦克风、功放
GPIO7 (DIN) → 麦克风
GPIO15 (DOUT) → 功放
```

**I2C总线**：
```
GPIO16 (SDA) → 触控、ath30
GPIO17 (SCL) → 触控、ath30
GPIO8 (INT) → 触控
```

**UART1**：
```
GPIO19 (TX) → LR22
GPIO20 (RX) → LR22
```

**其他**：
```
GPIO35 (M0) → LR22
GPIO36 (M1) → LR22
GPIO37 (AUX) → LR22
GPIO1 (ADC) → 电池检测
GPIO2 (LED) → 状态LED
```

#### 2.3 添加电源符号
- 添加VCC（3.3V）
- 添加GND
- 添加5V

#### 2.4 添加注释
在原理图上添加注释，说明：
- 禁用USB/JTAG
- I2C设备地址
- SPI设备片选

### 第3步：导入到PCB

1. 在原理图界面点击"导入到PCB"
2. 确认所有元件都已导入
3. 检查网络连接是否正确

### 第4步：PCB布局

#### 4.1 板框设置
1. 绘制板框（100mm x 80mm）
2. 设置板框属性：
   - 层：Board Outline
   - 线宽：0.1mm

#### 4.2 元件布局原则

**核心板位置**：
```
┌─────────────────────────────────────┐
│                                     │
│        ESP32-S3 核心板              │
│        (22x2排母)                   │
│                                     │
└─────────────────────────────────────┘
```

**布局原则**：
1. **核心板居中**：方便布线
2. **电源模块远离信号**：避免干扰
3. **模块按功能分组**：
   - 左侧：电源模块
   - 中间：核心板
   - 右侧：功能模块
4. **LoRa天线朝外**：避免被地平面遮挡

**推荐布局**：
```
┌──────────────────────────────────────────────────┐
│  ┌─────────┐                                     │
│  │ 电源模块 │  ← 3.3V/5V/GND                    │
│  │ 3个排母 │                                     │
│  └─────────┘                                     │
│                                                  │
│  ┌─────────────────────────────────────┐        │
│  │        ESP32-S3 核心板              │        │
│  │        (22x2排母)                   │        │
│  └─────────────────────────────────────┘        │
│                                                  │
│  ┌────────┐ ┌────────┐ ┌────────┐ ┌────────┐   │
│  │显示屏  │ │触控    │ │W25Q128 │ │ath30   │   │
│  │FPC转接 │ │FPC转接 │ │1x5排母 │ │1x4排母 │   │
│  └────────┘ └────────┘ └────────┘ └────────┘   │
│                                                  │
│  ┌──────────────────┐ ┌────────────┐            │
│  │ 麦克风 INMP441   │ │ 功放       │            │
│  │ 2x3排母          │ │ 1x7排母    │            │
│  └──────────────────┘ └────────────┘            │
│                                                  │
│                                    ┌────────┐   │
│                                    │LR22    │   │
│                                    │1x7排母 │   │
│                                    │  ┌──┐  │   │
│                                    │  │天│  │   │
│                                    │  │线│  │   │
│                                    │  └──┘  │   │
│                                    └────────┘   │
└──────────────────────────────────────────────────┘
```

#### 4.3 元件间距
- 排母之间：至少2mm
- 核心板与模块：至少5mm
- 天线区域：周围5mm内不走线

### 第5步：PCB布线

#### 5.1 设计规则设置
在"设计规则"中设置：

**线宽规则**：
- 电源线：≥1mm（建议1.5mm）
- 信号线：0.25mm（默认）
- 地线：≥1mm

**间距规则**：
- 最小间距：0.2mm
- 推荐间距：0.3mm

**过孔规则**：
- 过孔直径：0.6mm
- 过孔孔径：0.3mm

#### 5.2 布线原则

**电源线**：
```
1. 电源线尽量粗（≥1mm）
2. 电源线尽量短
3. 电源线先布
4. 大电流路径加粗（功放5V供电）
```

**信号线**：
```
1. SPI信号线尽量短（<50mm）
2. I2S信号线等长走线
3. I2C信号线加10K上拉电阻
4. 数字信号远离模拟信号
```

**地线**：
```
1. 铺铜处理（Bottom层铺GND铜皮）
2. 地平面完整
3. 避免地环路
```

#### 5.3 布线顺序

**第1步：电源线**
```
1. 5V电源线（粗线）
2. 3.3V电源线
3. GND线
```

**第2步：高速信号线**
```
1. SPI信号线（MOSI/MISO/SCLK）
2. I2S信号线（BCLK/WS/DIN/DOUT）
```

**第3步：其他信号线**
```
1. I2C信号线（SDA/SCL）
2. UART信号线（TX/RX）
3. GPIO控制线
```

**第4步：铺铜**
```
1. Bottom层铺GND铜皮
2. Top层铺GND铜皮（可选）
```

#### 5.4 特殊区域处理

**LoRa天线区域**：
```
1. 天线周围5mm内不走线
2. 天线周围不铺铜
3. 天线朝向板边
4. 天线下方不要有地平面
```

**电源区域**：
```
1. 电源模块区域单独铺铜
2. 电源线加粗
3. 添加去耦电容
```

### 第6步：设计规则检查（DRC）

1. 点击"设计规则检查"
2. 检查项目：
   - 线宽是否符合规则
   - 间距是否足够
   - 是否有未连接的网络
   - 是否有短路
3. 修复所有错误

### 第7步：添加丝印

**元件标识**：
```
1. 每个排母添加标识（如"J1"、"J2"）
2. 添加元件名称（如"ESP32-S3"、"LR22"）
3. 添加引脚标识（如"VCC"、"GND"）
```

**重要信息**：
```
1. 板子名称："ESP32-S3 Smart Assistant"
2. 版本号："V1.0"
3. 日期："2026-09"
4. 禁用USB/JTAG提醒
```

### 第8步：生成生产文件

1. 点击"生成生产文件"
2. 选择"嘉立创下单"
3. 生成Gerber文件
4. 下载并保存

## 三、注意事项

### 1. 电源注意事项

**去耦电容**：
```
在每个VCC引脚附近添加0.1uF去耦电容
- 核心板VCC
- 模块VCC
- 电源模块输出
```

**电源路径**：
```
1. 电源模块5V → 核心板5VIN → 板载LDO → 3.3V
2. 电源模块3.3V → 其他模块3.3V
3. 电源模块5V → 功放5V
```

### 2. 信号完整性注意事项

**SPI信号线**：
```
1. 尽量短（<50mm）
2. 避免直角走线（用45度或圆弧）
3. 三个设备尽量靠近
```

**I2S信号线**：
```
1. 等长走线（误差<5mm）
2. 避免交叉
3. 远离高频信号
```

**I2C信号线**：
```
1. 添加10K上拉电阻
2. 线宽0.25mm即可
3. 避免与其他信号平行走线
```

### 3. EMC注意事项

**地平面**：
```
1. Bottom层铺完整GND铜皮
2. 避免地平面开槽
3. 信号线下方保持地平面完整
```

**去耦**：
```
1. 每个VCC引脚加0.1uF电容
2. 电源入口加10uF电解电容
3. 高频器件加100nF电容
```

**屏蔽**：
```
1. LoRa天线区域净空
2. 高频信号线包地处理
3. 敏感信号线远离干扰源
```

### 4. 制造注意事项

**最小线宽**：
```
嘉立创最小线宽：0.15mm
推荐线宽：0.25mm
电源线宽：≥1mm
```

**最小间距**：
```
嘉立创最小间距：0.15mm
推荐间距：0.3mm
```

**过孔**：
```
最小过孔直径：0.4mm
推荐过孔直径：0.6mm
过孔孔径：0.3mm
```

### 5. 焊接注意事项

**排母焊接**：
```
1. 先焊接核心板排母（22x2）
2. 再焊接模块排母
3. 最后焊接电源排母
4. 焊接温度：320-350°C
```

**焊接顺序**：
```
1. 电源模块排母
2. 核心板排母
3. 模块排母
4. FPC转接排针
5. 其他元件
```

## 四、常见问题

### 1. 布线不通怎么办？
**解决方案**：
- 调整元件位置
- 添加过孔（从Top层到Bottom层）
- 使用0Ω电阻跳线

### 2. 电源线太细怎么办？
**解决方案**：
- 加粗电源线（≥1mm）
- 多层板可以多层铺铜
- 添加电源平面

### 3. 信号干扰怎么办？
**解决方案**：
- 信号线包地处理
- 添加去耦电容
- 调整信号线位置

### 4. 天线效果不好怎么办？
**解决方案**：
- 天线周围净空
- 天线朝向板边
- 天线下方不要有地平面
