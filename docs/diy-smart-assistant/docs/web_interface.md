# Web上位机设计文档

## 概述

本文档定义了ESP32-S3桌面智能助手的Web上位机界面，基于Mongoose Web服务器实现，提供设备监控、配置管理和远程控制功能。

## 功能模块

### 1. 设备状态监控
- **实时数据**: 电池电量、信号强度、设备温度
- **系统状态**: CPU使用率、内存使用、存储空间
- **网络状态**: WiFi连接、LoRa状态、蓝牙状态

### 2. LoRa通讯管理
- **设备列表**: 显示发现的LoRa设备
- **对讲控制**: 开始/停止对讲
- **留言管理**: 查看、发送、删除留言
- **通讯日志**: 实时显示通讯记录

### 3. 音频控制
- **录音控制**: 开始/停止录音
- **播放控制**: 播放/暂停/停止
- **音量调节**: 调节音量大小
- **音频文件**: 管理音频文件

### 4. 系统配置
- **WiFi配置**: 配置WiFi连接
- **LoRa配置**: 配置LoRa参数
- **音频配置**: 配置音频参数
- **显示配置**: 配置显示参数

### 5. 文件管理
- **W25Q128 Flash浏览**: 浏览W25Q128 Flash文件
- **文件上传**: 上传文件到W25Q128 Flash
- **文件下载**: 从W25Q128 Flash下载文件
- **文件删除**: 删除W25Q128 Flash文件

## API设计

### 1. REST API

#### 设备状态
```http
GET /api/device/status
```
响应:
```json
{
    "battery": 85,
    "wifi_connected": true,
    "ip_address": "192.168.1.100",
    "lora_online": true,
    "storage_used": 40,
    "uptime": 45296,
    "temperature": 45
}
```

#### LoRa设备列表
```http
GET /api/lora/devices
```
响应:
```json
{
    "devices": [
        {
            "id": 1,
            "name": "设备A",
            "status": "online",
            "battery": 90,
            "last_seen": "2026-09-03T14:30:00"
        }
    ]
}
```

#### 发送留言
```http
POST /api/lora/message
Content-Type: application/json

{
    "receiver_id": 1,
    "message_type": "audio",
    "data": "base64_encoded_audio_data"
}
```

#### 获取留言列表
```http
GET /api/lora/messages
```
响应:
```json
{
    "messages": [
        {
            "id": 1,
            "sender": "设备A",
            "type": "audio",
            "timestamp": "2026-09-03T14:30:00",
            "status": "unread"
        }
    ]
}
```

### 2. WebSocket API

#### 连接
```javascript
const ws = new WebSocket('ws://192.168.1.100/ws');
```

#### 消息格式
```json
{
    "type": "status_update",
    "data": {
        "battery": 85,
        "wifi_connected": true
    }
}
```

#### 消息类型
- `status_update`: 状态更新
- `lora_message`: LoRa消息
- `audio_data`: 音频数据
- `error`: 错误信息

### 3. JavaScript逻辑
```javascript
// WebSocket连接
class WebSocketClient {
    constructor(url) {
        this.ws = new WebSocket(url);
        this.ws.onmessage = this.onMessage.bind(this);
        this.ws.onclose = this.onClose.bind(this);
    }
    
    onMessage(event) {
        const data = JSON.parse(event.data);
        this.handleMessage(data);
    }
    
    handleMessage(data) {
        switch(data.type) {
            case 'status_update':
                this.updateStatus(data.data);
                break;
            case 'lora_message':
                this.handleLoRaMessage(data.data);
                break;
        }
    }
}

// API调用
class ApiClient {
    async getDeviceStatus() {
        const response = await fetch('/api/device/status');
        return response.json();
    }
    
    async sendLoRaMessage(message) {
        const response = await fetch('/api/lora/message', {
            method: 'POST',
            headers: {
                'Content-Type': 'application/json'
            },
            body: JSON.stringify(message)
        });
        return response.json();
    }
}
```
