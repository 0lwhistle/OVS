# ESP32-S3 智能助手开发技能

> **迁移说明 (2026-09-08)**: 本技能已从 Codex 迁移至 ZCode。移除了 Codex 专属的 `agents/openai.yaml`（UI配置）和技能内部独立日志 `logs/`，开发日志统一写入项目 `docs/development_log.md`。技能内 `references/` 为早期v1参考，以项目 `docs/` 文档为准。

## 概述

这是一个专门为ESP32-S3桌面智能助手项目开发的技能，提供代码模块化开发规范、日志管理系统和开发流程指导。

## 功能特性

### 1. 代码模块化开发
- 严格的模块划分规范
- 清晰的接口设计
- 标准化的代码结构

### 2. 日志管理系统
- 自动记录开发进度
- 问题追踪和解决方案
- 进度恢复功能

### 3. 开发流程指导
- 标准化的开发流程
- 代码质量规范
- 调试技巧指导

## 使用方法

### 1. 启动技能
当你需要开发ESP32-S3智能助手项目时，使用此技能：
```
我要开发ESP32-S3智能助手项目
```

### 2. 开发新模块
```
帮我开发LoRa通讯模块
```

### 3. 查看进度
```
查看开发进度日志
```

### 4. 解决问题
```
帮我解决音频播放延迟问题
```

## 日志系统

### 日志位置
`docs/development_log.md`（项目根目录下）

### 日志格式
每个日志条目包含：
- 日期时间
- 完成内容
- 进行中
- 待解决问题
- 解决方案
- 下一步计划
- 代码变更

### 日志读取
每次启动技能时自动读取日志，恢复开发上下文。

## 代码规范

### 命名规范
- 函数: `module_action`
- 变量: `module_variable`
- 类型: `module_type_t`
- 宏: `MODULE_CONSTANT`

### 代码格式
- 4空格缩进
- 清晰的注释
- 完善的错误处理

### 模块接口
每个模块提供：
- 初始化/反初始化
- 启动/停止
- 状态查询
- 回调设置

## 开发流程

### 1. 启动流程
```
读取日志 → 了解状态 → 制定任务
```

### 2. 开发流程
```
创建代码 → 遵循规范 → 测试验证 → 记录问题
```

### 3. 结束流程
```
记录进度 → 更新日志 → 制定计划
```

## 注意事项

1. **日志必须**: 每次开发必须记录日志
2. **模块化**: 严格遵循模块划分规范
3. **接口清晰**: 模块间通过标准接口通讯
4. **代码质量**: 清晰的命名和注释
5. **错误处理**: 完善的错误处理机制
6. **测试验证**: 每个功能都要测试验证
