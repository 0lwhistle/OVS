# 原理图元器件画法

## 一、去耦电容（Decoupling Capacitor）

### 符号
```
    │
    ═  0.1μF
    │
```

### 连接方式
每个模块的VCC引脚旁都需要放置一个0.1μF陶瓷电容：

```
VCC (3.3V) ──┬───────────── 模块VCC引脚
              │
              ═ 0.1μF
              │
GND ──────────┴───────────── 模块GND引脚
```

### 在原理图中的位置
```
        ┌─────────────────┐
        │                 │
VCC ────┤ VCC        GND ├──── GND
        │                 │
        └────────┬────────┘
                 │
                 ═ 0.1μF (靠近模块VCC引脚)
                 │
                GND
```

### 示例：ESP32-S3电源引脚
```
3.3V ──┬───────┬───────┬───────┬─────── ESP32-S3
       │       │       │       │
       ═       ═       ═       ═
      0.1μF   0.1μF   0.1μF   0.1μF
       │       │       │       │
GND ───┴───────┴───────┴───────┴───────
```

### 数量统计
| 模块 | VCC引脚数 | 电容数量 |
|------|-----------|----------|
| ESP32-S3 | 2 (3V3) | 2 |
| ST7789显示屏 | 1 (VDD) | 1 |
| CST816S触控 | 1 (AVDD) | 1 |
| W25Q128 | 1 (VCC) | 1 |
| INMP441麦克风 | 1 (VDD) | 1 |
| MAX98357A功放 | 1 (VIN) | 1 |
| LR22 LoRa | 1 (VCC) | 1 |
| ATH30传感器 | 1 (VDD) | 1 |
| **总计** | | **10** |

## 二、I2C上拉电阻

### 符号
```
    │
    ┤  4.7kΩ
    │
```

### 连接方式
I2C总线的SDA和SCL线需要上拉到VCC：

```
3.3V ────┬─────────────────────────────────
         │
         ┤ 4.7kΩ
         │
         ├───────────────────────────────── SDA (GPIO16)
         │
         ┤ 4.7kΩ
         │
         ├───────────────────────────────── SCL (GPIO17)
         │
        GND
```

### 在原理图中的位置
```
3.3V ──┬───────┬───────┬───────┬───────
       │       │       │       │
       ┤       ┤       │       │
      4.7kΩ   4.7kΩ    │       │
       │       │       │       │
       ├───────┼───────┼───────┼───────
       │       │       │       │
       │       │      ┌┴┐     ┌┴┐
       │       │      │ │     │ │
       │       │      │ │     │ │
       │       │      └┬┘     └┬┘
       │       │       │       │
      GND     GND    CST816S  ATH30
              (SDA)   (SCL)
```

### 数量
- SDA上拉：1个 4.7kΩ
- SCL上拉：1个 4.7kΩ
- **总计：2个**

## 三、电池电压分压电阻

### 符号
```
    │
    ┤  10kΩ
    │
    ├───── ADC输入 (GPIO1)
    │
    ┤  10kΩ
    │
```

### 连接方式
电池电压（最高8.4V）需要分压到0-3.3V供ADC检测：

```
电池正极 ─────┬─────────────────────
              │
              ┤ 10kΩ
              │
              ├───────────────────── GPIO1 (ADC)
              │
              ┤ 10kΩ
              │
GND ──────────┴─────────────────────
```

### 分压计算
```
Vout = Vin × R2 / (R1 + R2)
Vout = 8.4V × 10kΩ / (10kΩ + 10kΩ)
Vout = 8.4V × 0.5 = 4.2V

但是ESP32 ADC最大输入3.3V，所以需要调整：
- 方案1：使用3.3V稳压管保护ADC
- 方案2：调整分压比为 10kΩ + 20kΩ (分压比0.33)
- 方案3：使用ESP32内部ADC衰减（11dB衰减可检测0-3.3V）
```

### 推荐方案
使用ESP32内部ADC衰减功能，分压电阻保持10kΩ+10kΩ：

```c
// ESP32 ADC配置
adc1_config_width(ADC_WIDTH_BIT_12);
adc1_config_channel_atten(ADC1_CHANNEL_0, ADC_ATTEN_DB_11); // 0-3.3V

// 电压计算
float read_battery_voltage() {
    uint32_t adc_reading = adc1_get_raw(ADC1_CHANNEL_0);
    float voltage = (adc_reading * 3.3 / 4095) * 2.0; // 分压比2.0
    return voltage;
}
```

### 数量
- R1：1个 10kΩ
- R2：1个 10kΩ
- **总计：2个**

## 四、LED限流电阻（可选）

### 符号
```
    │
    ┤  470Ω
    │
    ▼  LED
    │
```

### 连接方式
```
GPIO2 ──── 470Ω ──── LED(+) ──── LED(-) ──── GND
```

### 在原理图中的位置
```
        ┌─────────────────┐
        │                 │
GPIO2 ──┤ GPIO2      GND ├──── GND
        │                 │
        └────────┬────────┘
                 │
                 ┤ 470Ω
                 │
                 ▼ LED
                 │
                GND
```

### 数量（可选）
- 限流电阻：1个 470Ω
- LED：1个
- **总计：2个（如果需要状态指示灯）**

## 六、PCB布局建议

### 去耦电容位置
```
┌─────────────────────────────────────┐
│                                     │
│  ┌─────┐  ═ 0.1μF                 │
│  │模块 │  │                        │
│  │VCC  ├──┘                        │
│  │GND  ├───────────────────────────│
│  └─────┘                           │
│                                     │
└─────────────────────────────────────┘

电容应放在模块VCC引脚旁边，距离<5mm
```

### I2C上拉电阻位置
```
┌─────────────────────────────────────┐
│                                     │
│  3.3V ──┬───────┬───────┬───────   │
│         │       │       │           │
│         ┤       ┤       │           │
│        4.7kΩ   4.7kΩ    │           │
│         │       │       │           │
│         ├───────┼───────┼───────   │
│         │       │       │           │
│        SDA     SCL    I2C设备      │
│                                     │
└─────────────────────────────────────┘

上拉电阻应放在I2C总线附近，靠近主控芯片
```

### 电池分压电阻位置
```
┌─────────────────────────────────────┐
│                                     │
│  电池+ ──┬───────┬───────┬───────  │
│          │       │       │          │
│         ┤       ┤       │          │
│        10kΩ    10kΩ     │          │
│          │       │       │          │
│          ├───────┼───────┼───────  │
│          │       │       │          │
│         GND    GPIO1   ESP32       │
│                                     │
└─────────────────────────────────────┘

分压电阻应靠近ADC引脚，减少噪声干扰
```

## 七、元器件清单汇总

| 类型 | 数量 | 规格 | 用途 |
|------|------|------|------|
| **去耦电容** | 10个 | 0.1μF 陶瓷电容 | 各模块VCC滤波 |

| **电池分压电阻** | 2个 | 10kΩ | 电池电压检测 |

- 必需：10个电容 + 4个电阻
- 可选：1个电阻 + 1个LED

## 八、注意事项

### 1. 电容选择
- **类型**：陶瓷电容（MLCC）
- **封装**：0402或0603
- **耐压**：≥10V
- **材质**：X7R或X5R

### 2. 电阻选择
- **类型**：贴片电阻
- **封装**：0402或0603
- **精度**：1%或5%
- **功率**：1/16W或1/8W

### 3. PCB布局原则
- 去耦电容：靠近VCC引脚，距离<5mm
- I2C上拉：靠近主控芯片
- 分压电阻：靠近ADC引脚
- 走线：尽量短，减少寄生参数
